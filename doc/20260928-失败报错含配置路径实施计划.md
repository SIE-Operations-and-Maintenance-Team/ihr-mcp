# 失败报错携带配置路径 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** MCP 工具调用失败时，报错信息携带配置文件绝对路径——凭据未配置时快速失败并指路（替代误导性的"账号或密码错误"），`get_login_status` 返回 `configPath`，SSO 登录失败信息追加路径提示。

**Architecture:** 三个触点、零新模块：①`tools.ts` 新增导出函数 `requireConfigOk(deps)`，`list_projects`/`fill_work_hours` 入口快速失败；②`get_login_status` 出参加 `configPath` 字段；③`session.ts` 登录失败抛错追加路径。路径一律运行时经 `defaultConfigPath()` 动态取（vitest 下解析为 `<仓库根>/src/config.json`，编译运行解析为 `<仓库根>/dist/config.json`，部署到哪都正确）。

**Tech Stack:** 既有栈不变（TypeScript、@modelcontextprotocol/sdk、vitest）；测试新增 InMemoryTransport 端到端脚手架（SDK 自带，无需网络）。

**Spec:** 需求来自用户指令（2026-09-28"调用失败的提示词要告诉路径"）+ 本计划 Global Constraints；文档同步落在 [doc/20260926-ihr-mcp设计文档.md](./20260926-ihr-mcp设计文档.md) §8 与 [doc/20260926-ihr-mcp实施计划.md](./20260926-ihr-mcp实施计划.md) 修订记录。

## Global Constraints

- 路径一律 `defaultConfigPath()` 动态取，**禁止硬编码** `dist\config.json` 字面量
- 报错文案（逐字）：快速失败 `凭据未配置: 请填写 <路径> 的 username/password 后重启服务`；登录失败追加 `（凭据配置: <路径>）`
- `requireConfigOk` 抛 `McpError(ErrorCode.InternalError, ...)`（tools.ts 既有 catch 对 McpError 原样透传，已核实 src/tools.ts catch 分支 `if (err instanceof McpError) throw err;`）
- 既有测试的子串断言必须保持通过（session.test.ts `toThrow('ihr 登录失败: 账号或密码错误 [code=40001]')` 是子串匹配，追加后缀兼容）
- 测试禁止真实网络调用（InMemoryTransport + 内存态 get_login_status 均无网络）
- TDD：先写失败测试再实现；收尾 `npm test` 全量 + `npm run build` 通过并 git commit（当前基线 41/41，预期 45/45：新增 session 1 + tools 3）

// （configOk 恒 false：本组用例只验证快速失败与状态查询，正向路径由 e2e 覆盖）
function makeDeps(): ToolDeps {
  const cfg: LoadConfigResult = {
    username: '在此填入ihr用户名',
    password: '在此填入ihr密码',
    port: 3210,
    host: '127.0.0.1',
    projectsRoot: 'F:\\项目',
    configOk: false,
  };
  return {
    cfg,
    session: new SessionManager(cfg),
    mapping: new MappingStore(join(mkdtempSync(join(tmpdir(), 'ihr-mcp-')), 'mapping.json')),
  };
}

async function callTool(deps: ToolDeps, name: string, args: Record<string, unknown> = {}) {
  const server = createMcpServer(deps);
  const client = new Client({ name: 'test', version: '0.0.0' });
  const [serverTransport, clientTransport] = InMemoryTransport.link();
  await Promise.all([server.connect(serverTransport), client.connect(clientTransport)]);
  try {
    return await client.callTool({ name, arguments: args });
  } finally {
    await client.close();
    await server.close();
  }
}

describe('失败报错携带配置路径（用户指令）', () => {
  it('get_login_status 返回 configPath（config.json 结尾）', async () => {
    const deps = makeDeps();
    const r = await callTool(deps, 'get_login_status');
    const payload = JSON.parse((r.content as any)[0].text);
    expect(payload.configPath).toMatch(/config\.json$/);
    expect(payload.configOk).toBe(false);
  });

  it('configOk=false 时 list_projects 快速失败并给出配置路径', async () => {
    const deps = makeDeps();
    await expect(callTool(deps, 'list_projects')).rejects.toThrow(
      /凭据未配置: 请填写 .+config\.json 的 username\/password 后重启服务/,
    );
  });

  it('configOk=false 时 fill_work_hours 同样快速失败（在参数校验之前）', async () => {
    const deps = makeDeps();
    await expect(
      callTool(deps, 'fill_work_hours', { entries: [{ date: 'bad' }] }),
    ).rejects.toThrow(/凭据未配置/);
  });
});
