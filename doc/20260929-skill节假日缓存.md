# ihr-attendance skill 节假日缓存实施文档

> 状态：**已确认并实施**（2026-09-29 用户确认设计后执行）

## 1. 需求

skill 原规则"法定节假日/调休无法准确判断，疑似列表待用户确认"导致：调休上班的周末（如 2026-09-20、2026-10-10）被误标 `加班`，法定节假日被当工作日出现在空档日提示。用户要求：doc 文件夹下缓存当年节假日数据，每年只拉取一次。

## 2. 方案选型（2026-09-29 联网实测）

- **holiday-cn（GitHub NateScarlet/holiday-cn）✅ 采用**：国务院公告自动抓取生成年度静态 JSON，免费无鉴权。`raw.githubusercontent.com` 与 jsDelivr CDN 镜像双源实测可用；agent 侧 WebFetch 实测可读。结构 `days:[{name,date,isOffDay}]`（true=放假/false=调休上班），`papers` 带 gov.cn 公告原文
- timor.tech API ❌：Cloudflare 人机验证拦截非浏览器通道（curl/WebFetch 均拿不到 JSON）
- chinese-calendar ❌：Python 库，不契合通用 agent 流程；其余第三方小站稳定性存疑

## 3. SKILL.md 改动（v1.2，纯 skill 侧，不动 ihr-mcp 代码）

1. 新增 **2.2 节假日缓存**：周期涉及年份 `<Y>` → 查 `<P>/doc/holidays-<Y>.json`，存在直接用；缺失则 WebFetch 拉取（raw → jsDelivr 镜像），落盘前校验 `year` 匹配 + `days` 非空；双源失败或 404（次年公告通常 11~12 月才发布）降级回退"疑似列表+用户确认"，不阻塞流程
2. 第 5 步周末规则：补**调休上班日例外**（`isOffDay=false` 的周末按工作日报 `工时`）
3. 第 5 步节假日规则：改为**按缓存判定**（放假日=加班，无痕迹不生成也不算空档日）
4. 空档日规则：排除法定节假日与无痕迹周末
5. 自查清单：新增节假日/调休一致性检查项
6. 第 6 步确认关口：列节假日与调休上班日清单 + 数据来源（本地缓存/本次拉取/降级人工确认）
7. 变更记录：补 v1.2 条目

## 4. 设计要点

- **每年每年份只拉一次**：以文件存在性为判断，无过期逻辑；跨年周期对涉及年份各查一次（最多两个文件）
- **不污染工作文档扫描**：`holidays-<Y>.json` 非 `.md`、不含 `YYYYMM` 六位月份模式，按名扫描与 mtime 补扫均不命中
- **缓存自愈**：内容损坏时删文件即重拉；校验防错内容落盘

## 5. 验证

- 已实测 2026.json：中秋 9/25~27 休、国庆 10/1~10/7 休、调休上班 9/20（周日）与 10/10（周六）——正是类型判定易错日
- skill 为 markdown 编排，无代码编译；三份副本（仓库/`.zcode`/`.agents`）同步一致
