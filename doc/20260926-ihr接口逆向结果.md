# ihr 接口逆向结果（2026-09-26）

> 任务：ihr 登录后接口逆向（Task 3）。
> 实证来源：登录后抓取的 ihr 前端 SPA（umi 3.5.41）主 bundle `/core/umi.97552d0e.js`、工时填报页 chunk `/core/p__form__WorkHoursFillIn.c4f0d7e6.async.js`（下称 whf.js）的 JS 代码引用，以及带凭据的 curl/Node 实调（2026-09-26）。
> 本文所有接口均已实调验证，除特别标注"推测/未实测"的条目。

## 0. 基础约定

- Base URL：`https://ihr.chinasie.com`（`http://` 会 301 到 https；注意 API 路径不在 `/core/` 下，`/core/` 仅是前端静态资源与路由前缀）。
- 统一响应包：`{"errorCode": "<字符串>", "errorMsg": "...", "data": ...}`，`errorCode === "0"` 表示成功。**HTTP 状态码通常恒为 200**，业务失败也返回 200（如未登录返回 200 + errorCode 401），客户端必须检查 errorCode 而不是 HTTP 状态码。
- 未登录/认证过期的错误响应（实测）：

```json
{"errorCode":"401","errorMsg":"系统未登录或认证已过期，请尝试刷新页面","data":null}
```

## 会话建立

- SSO 登录（`POST https://my.chinasie.com/certification/api/v1/certificate/login`，见 Task 2）成功后返回 JWT token，写入 cookie `token=<JWT>; Domain=chinasie.com; Path=/`。
- 访问 `http://ihr.chinasie.com/core/` 返回 **301 → https**，ihr 服务端**不另发任何会话 cookie**（实测 set-cookie 为空）。token cookie 直接对 ihr 域生效。
- **API 鉴权只认 `Authorization: Bearer <token>` 请求头，不认 cookie**（实测）：
  - 仅带 `Authorization: Bearer` → 200 errorCode 0（成功）
  - 仅带 `token` cookie → 200 errorCode 401（系统未登录）
  - 两者都不带 → 200 errorCode 401
  - 前端代码佐证：whf.js 中所有请求都从 cookie 读 token 并拼 `Authorization: "Bearer ".concat(token)` 头（umi.js 模块 94621）。
- 请求头约定（前端发送的完整集合）：`Accept: application/json, text/plain`、`Content-Type: application/json`（POST/PUT/DELETE）、`Authorization: Bearer <token>`。GET 请求仅 `Authorization` 头。
- JWT 有效期（实测解码 exp-iat）：约 7 天（604800 秒）。有效期是否可被服务端提前吊销未实测。
- **Task 4 注意**：当前 `src/sso/client.ts` 只写 cookie，调用 attendance/core API 时必须额外发送 `Authorization: Bearer` 头。

## 2. 考勤提交

前端有两个写入动作，请求体结构相同：

- **保存草稿**：`POST https://ihr.chinasie.com/attendance/api/v1/flow/ts/save`
- **提交（发起审批流）**：`POST https://ihr.chinasie.com/attendance/api/v1/flow/ts/start`

页面上的"保存"按钮走 save，"提交"按钮与"一键填报工时"弹窗都走 start（whf.js 函数 `cr`/`Zn` 实证）。

**填报周期口径**（whf.js `Rr`/`Kr` 函数实证）：默认按周（cycleUnit:"week"），dateList 由月内分段生成——每段以**周日**结尾（moment `.day(7)`），首段自当月 1 日起、末段截止到月末截断；完整周即**周一~周日**（上一切周期用 `startOf("isoWeek")` 即周一起始佐证）。`startDate`/`endDate` 取 dateList 首末日，与实测本周区间 2026-09-21(周一)~2026-09-27(周日) 一致。也可切整月（`month`）或自定义日期区间（`date`）。

### 3.4 删除/撤销填报（回滚用）

- `DELETE https://ihr.chinasie.com/attendance/api/v1/flow/ts/<type>/<id>`
